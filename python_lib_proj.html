Libraries & Projects

Introduction to Python Libraries

A library is a collection of reusable code that provides functionality for specific tasks.

Python has a large ecosystem of built-in modules and third-party libraries.

Libraries help developers avoid writing everything from scratch.

Installing Libraries Using pip

pip is the standard package installer commonly used for Python packages.

Syntax:


pip install library_name

Example:


pip install numpy
pip install pandas
pip install matplotlib

To see installed packages:


pip list

NumPy Library

NumPy is a Python library used for numerical computing and working with multidimensional arrays.

Installation:


pip install numpy

Importing NumPy:


import numpy as np

Creating an array:


import numpy as np

numbers = np.array([10, 20, 30, 40])

print(numbers)

Mathematical operations:


import numpy as np

a = np.array([10, 20, 30])
b = np.array([1, 2, 3])

print(a + b)
print(a * b)

Output:


[11 22 33]
[10 40 90]

Two-dimensional arrays:


import numpy as np

matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])


print(matrix)
print(matrix.shape)

Pandas Library

Pandas is used for data manipulation and analysis.

It provides two main data structures:

  • Series: One-dimensional labeled data.
  • DataFrame: Two-dimensional tabular data.

Installation:


pip install pandas

Creating a Series:


import pandas as pd

marks = pd.Series([85, 90, 78, 92])

print(marks)

Creating a DataFrame:


import pandas as pd

data = {
    "Name": ["Aman", "Ravi", "Neha"],
    "Marks": [85, 90, 92]
}

df = pd.DataFrame(data)

print(df)

Reading a CSV file:


import pandas as pd

df = pd.read_csv("students.csv")

print(df.head)

Useful Pandas functions:

Function Purpose
head() Displays first rows
tail() Displays last rows
info() Shows DataFrame information
describe() Generates descriptive statistics
shape Returns dimensions
isnull() Checks missing values
dropna() Removes missing values
fillna() Fills missing values
sort_values() Sorts data

Matplotlib Library

Matplotlib is used to create graphs and visualizations.

Installation:


pip install matplotlib

Creating a line graph:


import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [10, 20, 15, 30, 25]

plt.plot(x, y)

plt.title("Student Progress")
plt.xlabel("Week")
plt.ylabel("Marks")

plt.show()

Creating a bar chart:


import matplotlib.pyplot as plt

subjects = ["Math", "Python", "Physics"]
marks = [85, 90, 78]

plt.plot(subjects, marks)

plt.title("Subject Marks")
plt.xlabel("Subjects")
plt.ylabel("Marks")

plt.show()

Random Module

The random module generates pseudo-random values.


import random

print(random.randint(1, 100))

Selecting a random item:


import random

fruits = ["Apple", "Mango", "Banana"]

print(random.choice(fruits))

Datetime Module

The datetime module works with dates and times.


from datetime import datetime

today = datetime.now()

print(today)
print(today.date())
print(today.time())

Introduction to Virtual Environments

A virtual environment creates an isolated Python environment for a project.

It helps manage different project dependencies separately.

Create a virtual environment:


python -m venv .venv

Activate on Windows:


.venv\Scripts\activate

Activate on macOS/Linux:


source .venv/bin/activate

Install a package:


pip install pandas

Real-World Python Projects

These projects help you apply the concepts learned in the previous chapters.

Project 1 – Calculator

alculator

Objective: Build a calculator that performs basic mathematical operations.

Features:

  • Addition
  • Subtraction
  • Multiplication
  • Division
  • User input
  • Error handling

Example code:


def calculator(a, b, operator):

    if operator == "+":
        return a + b

    elif operator == "-":
        return a - b

    elif operator == "*":
        return a * b

    elif operator == "/":
        if b == 0:
            return "Cannot divide by zero"
        return a / b

    else:
        return "Invalid operator"


a = float(input("First number: "))
b = float(input("Second number: "))
operator = input("Enter operator (+, -, *, /): ")

print(calculator(a, b, operator))

Project 2 – Number Guessing Game

Beginner

Objective: Create a game in which the user tries to guess a randomly selected number.

Concepts used:

  • Random module
  • While loop
  • Conditional statements
  • User input

import random

number = random.randint(1, 100)

while True:
    guess = int(input("Guess a number: "))

    if guess < number:
        print("Too low")

    elif guess > number:
        print("Too high")

    else:
        print("Correct guess!")
        break

Project 3 – Student Management System

Intermediate

Objective: Store and manage student information.

Features:

  • Add student
  • Display student details
  • Search student
  • Update student
  • Delete student

Concepts used:

  • Lists
  • Dictionaries
  • Functions
  • Loops
  • Conditional statements

students = {}

def add_student(roll, name, marks):
    students[roll] = {
        "name": name,
        "marks": marks
    }

def display_students():
    for roll, details in students.items():
        print(roll, details)

add_student(101, "Aman", 85)
add_student(102, "Ravi", 90)

display_students()
