Python Fundamentals

1.1 Introduction to Python

What is Python?

Python is a high-level, interpreted, general-purpose programming language. It is known for its simple syntax and readability.

Python is used in:

  • Web development
  • Artificial intelligence (AI)
  • Machine learning
  • Data science
  • Automation
  • Software development
  • Game development

Example: First Python program


print("Hello, World!"")

Output:


Hello, World!

Explanation:

  • print() is a built-in Python function.
  • It displays information on the screen.
  • Text is written inside quotation marks.

1.2 Features of Python

  1. Easy to learn and understand.
  2. Free and open-source.
  3. Interpreted programming language.
  4. Supports object-oriented programming.
  5. Large collection of libraries.
  6. Cross-platform compatibility.
  7. Dynamically typed language.

1.3 Installing Python

To start programming:

  1. Download Python from https://www.python.org/
  2. Install Python on your computer.
  3. Open VS Code or Python IDLE.
  4. Create a file named main.py.
  5. Write your first Python program.
  6. Run the program.

1.4 Python Syntax

Syntax means the rules used to write a program.


name = "Rahul"
age = 20

print(name)
print(age)

Output:


Rahul
20

Python uses indentation (spaces at the beginning of a line) to define code blocks.

1.5 Comments in Python

Comments explain the code. Python does not execute comments.

Single-line comment:


# This is a single-line comment
print("Welcome to CodePath")

Multi-line explanation:



"""
This program demonstrates
how to display text in Python.
"""

print("Hello")

1.6 Variables in Python

A variable is a named storage location used to hold a value.


name = "Aman"
age = 18
city = "Delhi"


print(name)
print(age)
print(city)

Output:


Aman
18
Delhi

Rules for naming variables:

  • A variable name can contain letters, numbers and underscores.
  • It cannot start with a number.
  • Spaces are not allowed.
  • Python keywords cannot be used as variable names.
  • Variable names are case-sensitive.

Valid:


student_name = "Aman"
age1 = 18
total_marks = 450

Invalid:


1name = "Aman"
student name = "Aman"

1.7 Data Types in Python

A data type defines the kind of value stored in a variable.

Data type Meaning Example
int Integer numbers age = 18
float Decimal numbers price = 99.5
str Text name = "Aman"
bool True or False is_pass = True
list Ordered collection [10, 20, 30]
tuple Immutable collection (10, 20, 30)
set Unique elements {10, 20, 30}

Checking data types:


name = "Aman"
age = 18
marks = 85.5
is_pass = True


print(type(name))
print(type(age))
print(type(marks))
print(type(is_pass))

1.8 Taking Input from Users

The input() function takes information from the user.


name = input("Enter your name: ")

print("Welcome", name)

Example output:


Enter your name: Aman
Welcome Aman

Taking numerical input:


age = int(input("Enter your age: "))

print("Your age is:", age)

Important: input() returns a string by default. Use int() or float() when numerical input is required.

1.9 Type Conversion

Type conversion means changing one data type into another.



a = "25"

b = int(a)

print(b)
print(type(b))

Output:


 25
<class 'int'>

Common conversion functions:

  • int() – converts to an integer when possible.
  • float() – converts to a decimal number.
  • str() – converts to a string.
  • bool() – converts to a Boolean value.
  • list() – converts an iterable into a list.
  • tuple() – converts an iterable into a tuple.

1.10 Operators in Python

Operators perform operations on values and variables.

A. Arithmetic operators

Operator Meaning Example
+ Addition 10 + 5 = 15
i Subtraction 10 - 5 = 5
* Multiplication 10 * 5 = 50
/ Division 10 / 5 = 2.0
// Floor division 11 // 5 = 2
% Modulus 11 % 5 = 1
** Exponentiation 2 ** 3 = 8

Example:


a = 10
b = 3


print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)

B. Comparison operators

These operators compare two values and return True or False.


a = 10
b = 5


print(a == b)
print(a != b)
print(a > b)
print(a < b)
print(a >= b)
print(a <= b)

C. Logical operators

  • and – True when both conditions are True.
  • or – True when at least one condition is True.
  • not – Reverses a Boolean result.


age = 20

print(age > 18 and age < 60)
print(age < 18 or age > 60)
print(not age > 18)

D. Assignment operators



x = 10
x += 5
print(x)   # 15

x -= 3
print(x)   # 12

x *= 2
print(x)   # 24

E. Membership operators

in and not in check whether an item exists in a collection.


fruits = ["apple", "banana", "mango"]

print("apple" in fruits)
print("grapes" not in fruits)

F. Identity operators

is and is not check whether two references point to the same object.



name = "CodePath"
print(name)

String indexing:



text = "Python"

print(text[0])
print(text[1])
print(text[-1])

Output:


P
y
n

String slicing:


text = "Python Programming"

print(text[0:6])
print(text[7:18])

Important string methods:



name = "codepath"

print(name.upper())
print(name.capitalize())
print(name.title())
print(name.replace("code", "web"))
print(len(name))

Other useful methods include lower(), strip(), split(), find(), count() and startswith().

1.12 String Formatting

String formatting allows variables to be inserted into text.

Using f-strings:



name = "Aman"
age = 18

print(f"My name is {name} and I am {age} years old.")

Output:


My name is Aman and I am 18 years old.
