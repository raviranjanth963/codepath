JavaScript Standard Built-in Objects

1. Introduction to Standard Built-in Objects in JavaScript

JavaScript provides several standard built-in objects that help developers perform common programming tasks without writing everything from scratch.

These objects provide ready-made properties, methods, and functionality for working with strings, numbers, dates, arrays, mathematical calculations, errors, and more.

For example:

  • String helps us work with text.

  • Number helps us work with numeric values.

  • Math provides mathematical operations.

  • Date helps us work with dates and times.

  • Array helps us store and manage collections of data.

  • Object helps us create and manage objects.

  • JSON helps us convert JavaScript data into JSON format and back.

Example


let name = "Ravi Kumar";

console.log(name.toUpperCase());

Output:


RAVI KUMAR

Here, toUpperCase() is a built-in method that converts a string into uppercase letters.

2. What Are Built-in Objects?

Built-in objects are objects provided by JavaScript itself. They are available to use in your JavaScript programs without installing additional libraries.

JavaScript provides built-in objects for different purposes, such as:

  1. Working with text.

  2. Performing mathematical calculations.

  3. Handling dates and times.

  4. Managing arrays and collections.

  5. Working with objects and properties.

  6. Handling errors.

  7. Managing asynchronous operations.

  8. Working with structured data.

Important: Built-in objects are different from browser-specific Web APIs. For example, Array, String, and Promise are JavaScript built-ins, whereas document and localStorage are browser APIs.

Part A: Fundamental Built-in Objects

4. Object

The Object object is one of the most important built-in objects in JavaScript.

An object is used to store related information in the form of key-value pairs. It allows us to organize data and access or modify its properties.


const student = {
    name: "Ravi",
    age: 20,
    course: "JavaScript",
    isStudent: true
};

console.log(student);

Output:


{
  name: "Ravi",
  age: 20,
  course: "JavaScript",
  isStudent: true
}

Accessing object properties

There are two common ways to access object properties.

1. Dot notation


console.log(student.name);
console.log(student.age);

2. Bracket notation


console.log(student["name"]);
console.log(student["course"]);

Important Object methods

Method Description
Object.keys() Returns an array of an object's own enumerable property names.
Object.values() eturns an array of an object's own enumerable property values.
Object.entries() Returns an array of key-value pairs.
Object.assign() Copies properties from one or more source objects into a target object.
Object.freeze() Prevents changes to an object's own properties.
Object.seal() Prevents adding or removing properties, but existing writable properties can still change.
Object.hasOwn() Checks whether an object has a specific own property.
Object.create() Creates a new object with a specified prototype.

Example: Object.keys()


const student = {
    name: "Ravi",
    age: 20,
    course: "JavaScript"
};

console.log(Object.keys(student));

Output:


["name", "age", "course"]

Example: Object.values()


console.log(Object.values(student));

Output:


["Ravi", 20, "JavaScript"]

Example: Object.entries()


console.log(Object.entries(student));

Output:


[
    ["name", "Ravi"],
    ["age", 20],
    ["course", "JavaScript"]
]

Example: Object.hasOwn()


console.log(Object.hasOwn(student, "name")); 
// true

console.log(Object.hasOwn(student, "email")); 
// false

When should you use Object?

  • When storing student information.

  • When creating user profiles.

  • When storing product details.

  • When organizing related data.
