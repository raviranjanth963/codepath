Array

An Array is a built-in object used to store multiple values in a single variable.

Array elements are stored in an ordered collection, and each element has an index.

Important: JavaScript array indexing starts from 0, not 1.

Creating an array


const fruits = ["Apple", "Mango", "Banana", "Orange"];

console.log(fruits);

Accessing array elements


console.log(fruits[0]); // Apple
console.log(fruits[1]); // Mango
console.log(fruits[2]); // Banana

Array length

The length property returns the number of elements in an array.


console.log(fruits.length);

Output:


4

Important Array methods

Method Description
push() Adds an element to the end.
pop() Removes the last element.
unshift() Adds an element to the beginning.
shift() Removes the first element.
includes() Checks whether an element exists.
ndexOf() Returns the index of an element, or -1 if not found.
slice() Returns a shallow copy of a selected portion.
splice() Adds, removes, or replaces elements in an array.
join() Joins array elements into a string.
concat() Combines arrays and returns a new array
forEach() Executes a function for each element.
map() Creates a new array by transforming elements.
filter() Creates a new array containing elements that pass a condition.
find() Returns the first element that satisfies a condition.
reduce() Reduces an array to a single accumulated result.
sort() orts the elements of an array in place.
reverse() Reverses the array in place.

Example: push()

Adds an element to the end of an array.

Output:


const fruits = ["Apple", "Mango"];

fruits.push("Banana");

console.log(fruits);

Output:


["Apple", "Mango", "Banana"]

Example: pop()

Removes the last element.


fruits.pop();

console.log(fruits);

Output:


["Apple", "Mango"]

Example: map()

The map() method creates a new array by performing an operation on every element.


const numbers = [1, 2, 3, 4];

const result = numbers.map(num => num * 2);

console.log(result);

Output:


[2, 4, 6, 8]

Example: filter()

The filter() method creates a new array containing only the elements that satisfy a given condition.


const numbers = [10, 15, 20, 25, 30];

const result = numbers.filter(num => num > 20);

console.log(result);

Output:


[25, 30]

Example: reduce()

The reduce() method processes array elements and combines them into one final value.


const numbers = [10, 20, 30, 40];

const total = numbers.reduce(
    (sum, num) => sum + num,
    0
);

console.log(total);

Output:


100

When should you use Array?

  • When storing a list of students.

  • When creating a shopping cart.

  • When displaying products.

  • When storing multiple scores or marks.
