Advanced Topics

Intermediate to advanced

Goal Introduce concepts that help learners write more powerful queries, design better databases and understand how professional database systems work.

1. UNION

Combines the results of two or more SELECT statements and removes duplicate rows.


SELECT city FROM students
UNION
SELECT city FROM employees;

2. UNION ALL

Combines query results without removing duplicate rows.


SELECT city FROM students
UNION ALL
SELECT city FROM employees;

3. Subqueries

A subquery is a query inside another query.

Example: Find employees who earn more than the average salary.


SELECT *
FROM employees
WHERE salary > (
    SELECT AVG(salary)
    FROM employees
);

Important subquery operators

Operator Purpose
IN Check whether a value matches a list
EXISTS Check whether a subquery returns rows
ANY Compare against at least one returned value
ALL Compare against every returned value

Example:


SELECT *
FROM employees
WHERE department_id IN (
    SELECT department_id
    FROM departments
    WHERE location = 'Delhi'
);

4. Views

A View is a virtual table based on a stored SELECT query.


CREATE VIEW employee_details AS
SELECT name, salary
FROM employees;

Display the view:


SELECT * FROM employee_details;

Delete the view:


DROP VIEW employee_details;

5. Indexes

An Index helps MySQL find records more efficiently.


CREATE INDEX idx_employee_name
ON employees(name);

View indexes:


SHOW INDEX FROM employees;

Delete an index:


DROP INDEX idx_employee_name
ON employees;

Remember that indexes use storage and can make INSERT, UPDATE and DELETE operations more expensive.

6. Transactions

A transaction is a group of database operations treated as one logical unit.

Important commands:


START TRANSACTION;



COMMIT;



ROLLBACK;

Example:


START TRANSACTION;

UPDATE accounts
SET balance = balance - 1000
WHERE account_id = 1;

UPDATE accounts
SET balance = balance + 1000
WHERE account_id = 2;

COMMIT;

This example transfers ₹1,000 between two accounts.

7. ACID Properties

Property Meaning
Atomicity All operations succeed or the transaction is rolled back
Consistency Database rules remain valid
Isolation Concurrent transactions are controlled
Durability Committed changes persist

8. Normalization

Normalization organizes database tables to reduce unnecessary data duplication and improve data consistency.

Important forms:

  • 1NF – First Normal Form.
  • 2NF – Second Normal Form.
  • 3NF – Third Normal Form.

Example of a poorly structured table:

student_id name courses

A better approach is to keep separate student and course tables and use an enrollment table to connect them.

9. CTE – Common Table Expressions

A CTE is a named temporary result set defined using WITH.


WITH adult_students AS (
    SELECT *
    FROM students
    WHERE age >= 18
)
SELECT *
FROM adult_students;

CTEs make complex queries easier to understand.

10. Window Functions

Window functions calculate values across related rows without combining those rows into a single grouped row.

ROW_NUMBER():


SELECT
    name,
    salary,
    ROW_NUMBER() OVER (
        ORDER BY salary DESC
    ) AS row_num
FROM employees;

RANK():


SELECT
    name,
    salary,
    RANK() OVER (
        ORDER BY salary DESC
    ) AS employee_rank
FROM employees;

DENSE_RANK():


SELECT
    name,
    salary,
    DENSE_RANK() OVER (
        ORDER BY salary DESC
    ) AS employee_rank
FROM employees;
Function Purpose
ROW_NUMBER Unique sequential row number
RANK Ranking with gaps after ties
DENSE_RANK Ranking without gaps after ties

11. Stored Procedures

A stored procedure is a collection of SQL statements stored in the database.


DELIMITER //

CREATE PROCEDURE GetStudents()
BEGIN
    SELECT * FROM students;
END //

DELIMITER ;

Execute it:


CALL GetStudents();

12. Triggers

A trigger automatically executes when a specified event occurs on a table.

For example, record a log when a new student is added.


CREATE TABLE student_logs (
    log_id INT AUTO_INCREMENT PRIMARY KEY,
    student_name VARCHAR(100),
    action_time DATETIME
);

Create a trigger:


DELIMITER //

CREATE TRIGGER after_student_insert
AFTER INSERT ON students
FOR EACH ROW
BEGIN
    INSERT INTO student_logs
        (student_name, action_time)
    VALUES
        (NEW.name, NOW());
END //

DELIMITER ;
