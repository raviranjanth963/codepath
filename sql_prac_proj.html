Project 1: Student Management System

Objective: Create a database for managing students, courses and enrollments.

Create three tables:


CREATE TABLE students (
    student_id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE,
    age INT,
    city VARCHAR(50)
);



CREATE TABLE courses (
    course_id INT PRIMARY KEY AUTO_INCREMENT,
    course_name VARCHAR(100),
    fee DECIMAL(10,2)
);



CREATE TABLE enrollments (
    enrollment_id INT PRIMARY KEY AUTO_INCREMENT,
    student_id INT,
    course_id INT,
    enrollment_date DATE,
    FOREIGN KEY (student_id)
        REFERENCES students(student_id),
    FOREIGN KEY (course_id)
        REFERENCES courses(course_id)
);

Insert student data:


INSERT INTO students
(name, email, age, city)
VALUES
('Rahul', 'rahul@gmail.com', 20, 'Delhi'),
('Priya', 'priya@gmail.com', 19, 'Mumbai'),
('Aman', 'aman@gmail.com', 21, 'Patna');

Insert course data:


INSERT INTO courses
(course_name, fee)
VALUES
('HTML', 1000),
('CSS', 1200),
('SQL', 1500);

Insert enrollment data:


INSERT INTO enrollments
(student_id, course_id, enrollment_date)
VALUES
(1, 1, '2026-11-01'),
(1, 3, '2026-11-02'),
(2, 2, '2026-11-03'),
(3, 3, '2026-11-04');

Display student names and their courses:


SELECT
    students.name,
    courses.course_name,
    enrollments.enrollment_date
FROM enrollments
INNER JOIN students
    ON enrollments.student_id = students.student_id
INNER JOIN courses
    ON enrollments.course_id = courses.course_id;

Project 2: Employee Management System

Create an employee database containing:

  • Employee ID.
  • Employee name.
  • Email.
  • Salary.
  • Department.
  • Joining date.

Students should practise searching employees, calculating average salaries, finding the highest-paid employee and grouping employees by department.

Suggested tables:

  • Customers.
  • Products.
  • Orders.
  • Order Details.

Students should practise product searches, total sales calculations, customer order history and joins between related tables.
