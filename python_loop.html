Conditions & Loops

Introduction to Conditional Statements

Conditional statements allow a program to make decisions based on conditions.

Python provides:

  • if
  • if-else
  • if-elif-else
  • Nested if statements

The if Statement

The if statement executes a block of code only when its condition is True.

Sy 

if condition:
      statement

Example:


age = 20

if age >= 18:
    print("You are eligible to vote.")

Output:


You are eligible to vote.

The if-else Statement

The else block executes when the if condition is False.


age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")

Output:


Minor

The if-elif-else Statement

Use elif when multiple conditions need to be checked.


marks = 82

if marks >= 90:
    print("Grade A+")
elif marks >= 80:
    print("Grade A")
elif marks >= 70:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
else:
    print("Needs Improvement")

Output:


Grade A

Nested if Statements

An if statement written inside another if statement is called a nested if statement.


age = 20
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed")
    else:
        print("ID required")
else:
    print("Entry not allowed")

Introduction to Loops

Loops are used to execute a block of code repeatedly.

Python has two main types of loops:

  1. for loop
  2. while loop

The for Loop

A for loop is used to iterate over a sequence such as a string, list, tuple or range.

Syntax:


for variable in sequence:
    statement

Example:


for  in range(1, 6):
    print(i)

Output:


1
2
3
4
5

Understanding the range() Function

The range() function generates a sequence of integers.

Three common forms:


range(5)
range(1, 6)
range(1, 10, 2)
Expression Generated values
range(5) 0, 1, 2, 3, 4
range(1, 6) 1, 2, 3, 4, 5
range(1, 10, 2) 1, 3, 5, 7, 9

The while Loop

A while loop executes as long as its condition remains True.

Syntax:


while condition:
    statement

Example:


i = 1

while i <= 5:
    print(i)
    i  += 1

Output:


1
2
3
4
5

Important: Update the loop variable when necessary. Otherwise, a loop may continue indefinitely.

break Statement

The break statement immediately terminates the nearest enclosing loop.


for i in range(1, 10):
    if i == 5:
        break
    print(i)

Output:


1
2
3
4

continue Statement

The continue statement skips the current iteration and moves to the next iteration.


for i in range(1, 6):
    if i == 3:
        continue
    print(i)

Output:


1
2
3
4
5

pass Statement

The pass statement is a placeholder. It does nothing when executed.


for i in range(5):
    if i == 2:
        pass
    print(i)

Nested Loops

A loop inside another loop is called a nested loop.


for i in range(1, 4):
    for j in range(1, 4):
    print(i, j)

Pattern Programming

Loops can be used to print different patterns.

Example 1:


for i in range(1, 6):
    print("*" * j)

Output:


*
**
***
****
*****

Example 2:


for i in range(1, 0, -1):
    print("*" * i)

Output:


*****

***
**
*

Practical Example – Even and Odd Numbers


num = int(input("Enter a number: "))

if num % 2 == 0:
    print("Even number")
else:
    print("Odd number")

Practical Example – Multiplication Table


num = int(input("Enter a number: "))

for i in range(1, 11):
    print(f"{num} x {i} = {num * i}")
