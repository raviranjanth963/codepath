MySQL Installation

Setup your computer

Goal: Help learners download MySQL, install it and prepare their computer for writing SQL queries.

1. Where to download MySQL?

MySQL Community Server
Download Worbench:-
Official database server download.

2. Where to download MySQL Workbench?

MySQL Workbench
Download Worbench:-
Graphical interface for writing SQL queries.

3. Windows installation steps

  1. Visit the official MySQL website.
  2. Select Windows.
  3. Download the appropriate installer.
  4. Open the downloaded installer.
  5. Follow the installation wizard.
  6. Configure MySQL Server.
  7. Set your root password.
  8. Complete the installation.
  9. Open MySQL Workbench.
  10. Connect to your local MySQL server.

4. MacBook installation steps

  1. Visit the official MySQL website.
  2. Select macOS.
  3. Choose the correct processor package: Apple Silicon or Intel.
  4. Download the DMG file.
  5. Open the downloaded package.
  6. Follow the installation instructions.
  7. Configure MySQL Server.
  8. Set your root password.
  9. Install MySQL Workbench.
  10. Connect to your local server.

5. Linux installation

For Ubuntu or Debian:


sudo apt update
sudo apt install mysql-server

Start the service:


sudo systemctl start mysql

Open the MySQL client:


sudo mysql

6. Verify your installation

Run:


SELECT VERSION();

This displays your installed MySQL version.

Your first SQL query:


SELECT "Welcome to CodePath!" AS message;
