Database Operations

Core SQL commands

Goal: Teach students how to create databases, make tables, insert data, retrieve records, filter information and manage existing records.

This should be one of the largest sections of your SQL course because it covers the daily work of a database developer.

1. CREATE DATABASE

Creates a new database.


CREATE DATABASE codepath;

Check available databases:


SHOW DATABASES;

Select your database:


USE codepath;

2. CREATE TABLE

A table stores information in rows and columns.


CREATE TABLE students (
    id INT,
    name VARCHAR(100),
    age INT,
    city VARCHAR(50)
);

Display the table structure:


DESCRIBE students;

3. INSERT Command

Adds new records to a table.


INSERT INTO students
(id, name, age, city)
VALUES
(1, 'Rahul', 20, 'Delhi'),
(2, 'Priya', 19, 'Mumbai'),
(3, 'Aman', 21, 'Patna'),
(4, 'Sneha', 20, 'Jaipur');

4. SELECT Command

Retrieves records from a table.

All columns:


SELECT * FROM students;

Selected columns:


SELECT name, age FROM students;

Unique cities:


SELECT DISTINCT city FROM students;

5. WHERE Clause

Filters records based on a condition.


SELECT *
FROM students
WHERE city = 'Delhi';

6. SQL Operators

Operator Meaning
= Equal
!= Not equal
> Greater than
< Less than
>= Greater than or equal
<= Less than or equal
AND Both conditions must be true
OR At least one condition must be true
NOT Reverse a condition
BETWEEN Check a range
IN Match values in a list
LIKE Pattern matching
IS NULL Check missing values

Examples:


SELECT * FROM students
WHERE age >= 20 AND city = 'Delhi';



SELECT * FROM students
WHERE city IN ('Delhi', 'Mumbai');



SELECT * FROM students
WHERE name LIKE 'A%';

7. ORDER BY

Sort records:


SELECT * FROM students
ORDER BY age ASC;

Descending order:


SELECT * FROM students
ORDER BY age DESC;

8. LIMIT

Display only the first three records:


SELECT * FROM students
LIMIT 3;

Pagination example:


SELECT * FROM students
LIMIT 10 OFFSET 10;

9. UPDATE

Modify existing records:


UPDATE students
SET city = 'Bangalore'
WHERE id = 1;

10. DELETE

Delete selected records:


DELETE FROM students
WHERE id = 4;

11. SQL Functions

String functions:


SELECT UPPER('codepath');
SELECT LOWER('CODEPATH');
SELECT LENGTH('CodePath');
SELECT CONCAT('Code', 'Path');
SELECT TRIM('   CodePath   ');

Numeric functions:


SELECT ROUND(12.567, 2);
SELECT ABS(-25);
SELECT CEIL(12.3);
SELECT FLOOR(12.9);

Date functions:


SELECT NOW();
SELECT CURDATE();
SELECT CURTIME();
SELECT YEAR('2026-11-04');

NULL functions:


SELECT IFNULL(NULL, 'Not Available');

SELECT COALESCE(NULL, 'CodePath');

12. Aggregate Functions

Function Purpose
COUNT() Count records
SUM() Calculate total
AVG() Calculate average
MAX() Find highest value
MIN() Find lowest value

Example:


SELECT COUNT(*) FROM students;

13. GROUP BY

Groups records with matching values.


SELECT city, COUNT(*) AS total_students
FROM students
GROUP BY city;

14. HAVING

Filters grouped results.


SELECT city, COUNT(*) AS total_students
FROM students
GROUP BY city
HAVING COUNT(*) > 1;

15. ALTER TABLE

Add a new column:


ALTER TABLE students
ADD email VARCHAR(100);

Remove a column:


ALTER TABLE students
DROP COLUMN email;

Modify a column:


ALTER TABLE students
MODIFY COLUMN name VARCHAR(150);

Rename a column:


ALTER TABLE students
CHANGE COLUMN name full_name VARCHAR(150);

Rename a table:


ALTER TABLE students
RENAME TO learners;

16. TRUNCATE

Removes all records from a table without removing its structure.


TRUNCATE TABLE students;

17. Important differences

Commands Difference
DELETE vs TRUNCATE DELETE can filter rows; TRUNCATE removes all rows
DELETE vs DROP DELETE removes rows; DROP removes the table
WHERE vs HAVING WHERE filters rows; HAVING filters groups
ORDER BY vs GROUP BY ORDER BY sorts; GROUP BY groups

Important Always verify conditions before running UPDATE or DELETE. TRUNCATE and DROP are structural operations in MySQL that cause implicit commits.
