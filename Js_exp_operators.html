JavaScript Expressions and Operators

1. Introduction to Expressions and Operators

Expressions and operators are fundamental concepts in JavaScript. They are used to perform calculations, compare values, assign data to variables, make decisions, and manipulate information.

Almost every JavaScript program uses expressions and operators.

Exampe


let a = 10;
let b = 20;

let sum = a + b;

console.log(sum);

Output:


30

In this example:

  • a and b are variables.

  • 10 and 20 are values.

  • + is an arithmetic operator.

  • a + b is an expression.

  • sum stores the result of the expression.

2. What Is an Expression in JavaScript?

An expression is a valid combination of values, variables, operators, and function calls that evaluates to a value.

Expressions can be simple or complex.

Example 1: Literal expression


10

 The expression age evaluates to: 10

Example 2: Arithmetic expression


10 + 20

Output: 30

Example 3: Variable expression


let age = 25;

age

 The expression age evaluates to: 25

Example 4: Assignment expression


let x = 10;

x = 20;

Here, x = 20 is an assignment expression. It assigns 20 to x and itself evaluates to 20.

Example 5: Function call expression


function add(a, b) {
    return a + b;
}

add(10, 20);

Output:


30

The function call add(10, 20) is an expression because it produces a value.

Example 6: Conditional expression


let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);

Output:


Adult

The conditional expression evaluates to either "Adult" or "Minor"

3. Types of Expressions

avaScript expressions can be grouped according to what they do.

A. Arithmetic Expressions

Arithmetic expressions perform mathematical calculations.


let result = 10 + 20 * 2;

console.log(result);

Output:


50

B. Assignment Expressions

Assignment expressions assign values to variables.


let age = 20;

age = 25;

console.log(age);

Output:


25

C. Comparison Expressions

Comparison expressions compare two values and return a Boolean result (true or false).


let a = 10;
let b = 20;

console.log(a < b);

 output: true

D. Logical Expressions

Logical expressions combine or invert conditions.


let age = 25;
let hasID = true;

console.log(age >= 18 && hasID);

 output: true

E. String Expressions

String expressions combine or manipulate text.


let firstName = "Ravi";
let lastName = "Kumar";

let fullName = firstName + " " + lastName;

console.log(fullName);

 output: Ravi Kumar

F. Conditional Expressions

Conditional expressions return a value based on a condition.


let age = 17;

let status = age >= 18 ? "Eligible" : "Not eligible";

console.log(status);

Output:


Not eligible

4. What Is an Operator in JavaScript?

An operator is a special symbol or keyword that performs an operation on one or more values.

The values on which an operator performs an operation are called operands.

Example


let result = 10 + 20;

Here

  • 10 is the first operand.

  • 20 is the second operand.

  • + is the operator.

  • 10 + 20 is the expression.

5. Types of Operators Based on the Number of Operands

JavaScript operators can also be classified according to how many operands they require.

A. Unary Operators

A unary operator works with only one operand

example


let a = 10;

console.log(-a);

Output: -10

Here, the unary minus (-) operator works on one operand, a.

Other unary operators include:

  • ++ – Increment

  • -- – Decrement

  • ! – Logical NOT

  • typeof – Checks the type of a value

  • delete – Deletes an object property

B. Binary Operators

binary operator works with two operands.

Example


let a = 10;
let b = 20;

console.log(a + b);

Output: 30

Here, + operates on two operands, a and b.

Other binary operators include:

  • -

  • *

  • /

  • %

  • **

  • ==

  • ===

  • >

  • <

  • &&

  • ||

C. Ternary Operator

A ternary operator works with three operands.

JavaScript has one conditional operator, written as ? :.

Example


let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);

Output: Adult

Example of All :--

When one operand is a string, the + operator generally performs string concatenation rather than numeric addition.


console.log("10" + 20); // "1020"
console.log(10 + 20);   // 30

Multiplication Operator (*)


let a = 10;
let b = 5;

Output: 50

Division Operator (/)


let a = 100;

console.log(a / b);

Output: 10

Remainder Operator (%)


let a = 10;
let b = 3;

Output: 1

let number = 10;

if (number % 2 === 0) {
    console.log("Even Number");

Output:


Even Number

console.log(5 ** 2); // 25
console.log(3 ** 3); // 27
console.log(10 ** 2); // 100

Increment and Decrement Operators

Increment and decrement operators are unary operators used to increase or decrease a numeric value by one.

Increment Operator (++)

The increment operator increases a variable's value by 1.

There are two types of increment operators:

A. Pre-increment (++variable)

The variable is increased first, and then its updated value is used in the expression.


let a = 10;

console.log(++a);
console.log(a);

Output:


11
11

B. Post-increment (variable++)

The current value is used in the expression first, and then the variable is increased by 1.


let a = 10;

console.log(a++);
console.log(a);

Output:


10
11

Difference between pre-increment and post-increment

Pre-increment Post-increment
++a a++
Increments before producing the expression's value. Produces the old value before incrementing.
Returns the updated value. Returns the previous value.

Decrement Operator (--)

The decrement operator decreases a variable's value by 1.

It also has two types.

A. Pre-decrement (--variable)


let a = 10;

console.log(--a);
console.log(a);

output:


9
9

B. Post-decrement (variable--)


let a = 10;

console.log(a--);
console.log(a);

Output:


10
9

Practical example


let score = 100;

score++;

console.log(score); // 101

score--;

console.log(score); // 100

Important: Increment and decrement operators work with variables that can be modified, not with literal values such as 10++.
