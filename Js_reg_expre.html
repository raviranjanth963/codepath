RegExp (Regular Expressions)

RegExp stands for Regular Expression>.

It is used to define patterns for searching, matching, and replacing text.

Regular expressions are useful for validating email addresses, checking phone numbers, and finding specific words in text.

Creating a regular expression


const pattern = /hello/i;

Here:

  • /hello/ is the pattern.

  • i is a flag that makes the matching case-insensitive.

Important RegExp methods

Method Description
test() Checks whether a pattern exists in a string.
exect() Returns matching information or null.

Strings also provide regular-expression methods such as match(), replace(), and search().

Example: test()


const pattern = /javascript/i;

console.log(pattern.test("I love JavaScript"));

Output:


true

Example: Checking digits


const pattern = /^[0-9]+$/;

console.log(pattern.test("12345"));
// true

console.log(pattern.test("Hello123"));
// false

Explanation:

  • ^ represents the beginning of the string.

  • [0-9] matches digits from 0 to 9.

  • + means one or more occurrences.

  • $ represents the end of the string.

When should you use RegExp?

  • When validating form inputs.

  • When searching for specific words.

  • When checking phone number patterns.

  • When finding and replacing text.
