Data Structures

Introduction to Data Structures

Data structures are ways of organizing and storing data so that it can be accessed and modified efficiently.

Python provides four important built-in collection data types:

  1. List
  2. Tuple
  3. Set
  4. Dictionary

Lists in Python

A list is an ordered and mutable collection that allows duplicate values.

Creating a list:



fruits = ["Apple", "Banana", "Mango"]

print(fruits)

Accessing list elements:


fruits = ["Apple", "Banana", "Mango"]

print(fruits[0])
print(fruits[1])
print(fruits[-1])

Changing list elements:


fruits = ["Apple", "Banana", "Mango"]

fruits[1] = "Orange"

print(fruits)

Important list methods:

Method Purpose
append() Adds an item at the end
insert() Adds an item at a specified position
extend() Adds multiple items
remove() Removes a specified item
pop() Removes and returns an item
sort() Sorts the list
reverse() Reverses the list
clear() Removes all elements
index() Returns an item's position
count() Counts occurrences

Example:


numbers = [10, 20, 30]

numbers.append(40)
numbers.insert(1, 15)
numbers.remove(30)

print(numbers)

Output:


[10, 15, 20, 40]

List Slicing

A tuple is an ordered and immutable collection.

Once a tuple is created, its elements cannot be reassigned.


numbers = (10, 20, 30, 40)

print(numbers)
print(numbers[0])
print(numbers[2])

Important tuple methods:

  • count()
  • index()

Single-element tuple:


value = (10,)
print(type(value))

The comma is necessary to create a single-element tuple.

Sets in Python

A set is an unordered collection of unique elements.


numbers = {10, 20, 30, 10}

print(numbers)

Output contains only one occurrence of 10. Set display order is not guaranteed.

Important set methods:


numbers = {10, 20, 30}

numbers.add(40)
numbers.update([50, 60])
numbers.remove(20)

print(numbers)

Other methods include discard(), pop(), clear() and copy().

Set Operations

Suppose:


A= {1, 2, 3, 4}
B = {3, 4, 5, 6}

Union: Combines all unique elements.


print(A | B)

Intersection: Returns common elements.


print(A & B)

Difference: Returns elements in A that are not in B.


print(A - B)

Symmetric difference: Returns elements present in either set, but not both.


print(A ^ B)

Dictionaries in Python

A dictionary stores information in key-value pairs.


student = {
    "name": "Aman",
    "age": 18,
    "branch": "AI&DS"
}

print(student["name"])
print(student["age"])

Adding and updating values:


student["college"] = "ADGITM"
student["age"] = 19

print(student)

Important dictionary methods:

Method Purpose
keys() Returns all keys
values() Returns all values
items() Returns key-value pairs
get() Safely retrieves a value
update() Updates dictionary
pop() Removes a key
clear() Removes all entries
copy() Creates a shallow copy

Iterating Through Dictionaries


student = {
    "name": "Aman",
    "age": 18,
    "branch": "AI&DS"
}

for key, value in student.items():
    print(key, ":", value)

List Comprehension

List comprehension provides a shorter way to create a list.

Normal method:


squares = []

for i in range(1, 6):
    squares.append(i * i)

print(squares)

Using list comprehension:


squares = [i * i for i in range(1, 6)]

print(squares)

Output:


[1, 4, 9, 16, 25]

With a condition:


even = [i for i in range(1, 11) if i % 2 == 0]

print(even)

Nested Data Structures

A data structure can contain another data structure.


students = [
    {"name": "Aman", "marks": 85},
    {"name": "Ravi", "marks": 90},
    {"name": "Neha", "marks": 88}
]

for student in students:
    print(student["name"], student["marks"])
