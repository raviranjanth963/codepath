Functions & Modules

Introduction to Functions

A function is a reusable block of code designed to perform a particular task.

Functions help:

  • Reduce repeated code.
  • Improve readability.
  • Organize programs.
  • Make debugging easier.
  • Divide large programs into smaller tasks.

Defining a Function

Python uses the def keyword to define a function.

Syntax:


def function_name():
    statements

Example:


def greet():
    print("Welcome to CodePath")

greet()

Output:


Welcome to CodePath

Function Parameters and Arguments

Parameters are variables defined in the function definition. Arguments are the actual values passed when calling the function.


def greet(name):
    print("Hello", name)

greet("Aman")

Output:


Hello Aman

Return Statement

The return statement sends a result back to the calling code.


def add(a, b):
    return a + b

result = add(10, 20)

print(result)

Output:


30

Difference:

  • print() displays a value.
  • return sends a value back from a function.

Types of Function Arguments

A. Positional arguments


def student(name, age):
    print(name, age)

student("Aman", 18)

B. Keyword arguments


student(age=18, name="Aman")

C. Default arguments


def greet(name="Student"):
    print("Hello", name)

greet()
greet("Aman")

D. Variable-length positional arguments (*args)


def total(*numbers):
    print(sum(numbers))

total(10, 20, 30, 40)

E. Variable-length keyword arguments (**kwargs)


def details(**info):
    for key, value in info.items():
        print(key, value)

details(name="Aman", age=18, branch="AI&DS")

Scope of Variables

Scope determines where a variable can be accessed.

Local variable:

A variable created inside a function.


def show():
    message = "Hello"
    print(message)

show()

Global variable:

A variable defined outside a function.


name> = "CodePath"

def show():
    print(name)

show()

The global keyword allows a function to reassign a global variable.


count = 10

def update():
    global count
    count = 20

update()
print(count)

Lambda Functions

A lambda function is a small anonymous function written using the lambda keyword.

Syntax:


lambda arguments: expression

Example:


square = lambda x: x * x

print(square(5))

Output:


25

Recursion

Recursion occurs when a function calls itself.

Every recursive function should have a base case to stop the recursive calls.

Example – Factorial:


def factorial(n):
    if n == 0 or n == 1:
        return 1

    return n * factorial(n - 1)

print(factorial(5))

Output:


120

Modules in Python

A module is a Python file containing reusable functions, variables and classes.

ython provides built-in modules and also allows users to create their own modules.

Using a built-in module:


import math

print(math.sqrt(25))
print(math.factorial(5))
print(math.pi)

Different Ways to Import Modules

Import the complete module:


import math

print(math.sqrt(16))

Import a specific function:


from math import sqrt

print(sqrt(16))

Using an alias:


import math as m

print(m.sqrt(36))

Creating Your Own Module

Create a file called calculator.py:


def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

Create another file called main.py:


import calculator

print(calculator.add(10, 5))
print(calculator.subtract(10, 5))

Output:


15
5

Packages in Python

A package is a way of organizing related Python modules into a directory structure.

For example:


my_package/
    __init__.py
    calculator.py
    greetings.py

main.py

Packages help organize larger applications.
