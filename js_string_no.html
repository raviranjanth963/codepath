String

The String object provides methods and properties for working with text.

A string is a sequence of characters enclosed in quotation marks.

Creating strings


let firstName = "Ravi";
let lastName = 'Kumar';

console.log(firstName);
console.log(lastName);

You can also create a string using the String() function:


let age = String(20);

console.log(age);
console.log(typeof age);

Output:


20
string

Important String properties and methods

Method / Property Description
length Returns the number of UTF-16 code units in a string.
toUpperCase() Converts text to uppercase.
toLowerCase() Converts text to lowercase.
trim() Removes whitespace from both ends.
trimStart() Removes whitespace from the beginning.
trimEnd() Removes whitespace from the end.
includes() Checks whether a string contains specified text.
indexOf() Finds the first occurrence of specified text.
slice() Extracts a portion of a string.
replace() Replaces the first matching occurrence.
replaceAll() Replaces all matching occurrences.
split() Splits a string into an array.
charAt() Returns the character at a specified position.
startsWith() Checks whether a string starts with specified text.
endsWith() Checks whether a string ends with specified text.
repeat() Repeats a string a specified number of times.

Example: toUpperCase()


let message = "hello world";

console.log(message.toUpperCase());

Output:


HELLO WORLD

Example: toLowerCase()


let message = "HELLO WORLD";

console.log(message.toLowerCase());

Output:


hello world

Example: trim()


let name = "   Ravi Kumar   ";

console.log(name.trim());

Output:


Ravi Kumar

Example: includes()


let message = "Welcome to JavaScript";

console.log(message.includes("JavaScript"));

Oputut:


true

Example: slice()


let text = "JavaScript";

console.log(text.slice(0, 4));

Output:


Java

Example: split()


let fruits = "Apple, Mango, Banana";

console.log(fruits.split(", "));

Oputut:


["Apple", "Mango", "Banana"]

Important: Strings are immutable in JavaScript. This means string methods return new strings rather than changing the original string.



Number

The Number object provides properties and methods for working with numeric values.

JavaScript uses the Number type for ordinary integer and floating-point numbers.

Example


let price = 99.99;
let age = 20;

console.log(price);
console.log(age);

Important Number methods

Method Description
Number() Converts a value into a number where possible.
Number.isInteger() Checks whether a value is an integer.
Number.isNaN() Checks whether a value is the numeric NaN.
Number.isFinite() Checks whether a value is a finite number.
Number.parseInt() Parses an integer from a string.
Number.parseFloat() Parses a floating-point number from a string.
toFixed() Formats a number using a specified number of decimal places.
toString() Converts a number into a string.
toPrecision() Formats a number to a specified number of significant digits.

Example: Number()


let value = "100";

console.log(Number(value));

output:


100

Example: Number.isInteger()


console.log(Number.isInteger(20)); 
// true

console.log(Number.isInteger(20.5)); 
// false

Example: Number.isNaN()


console.log(Number.isNaN(NaN)); 
// true

console.log(Number.isNaN("Hello")); 
// false

Example: toFixed()


let price = 99.5678;

console.log(price.toFixed(2));

Output:


99.57

When should you use Number?

  • When calculating prices.

  • When checking marks and scores.

  • When converting user input into numbers.

  • When formatting decimal values.
