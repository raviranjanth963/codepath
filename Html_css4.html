Step: 1

There are many websites and apps for coding, such as CodePen, Replit, and JSFiddle. However, you can download and install Visual Studio Code (VS Code) to start coding on your computer.

Visual Studio Code (VS Code) vs code.

After installing VS Code, follow these steps:

  1. Install the Live Server extension in VS Code.
  2. Create a folder for your project.
  3. Inside that folder, create two files: index.html and style.css.
  4. Write your HTML code in index.html and your CSS code in style.css.
  5. Connect the CSS file to the HTML file using the tag.

    6. <link rel="stylesheet" href="style.css">

  6. Right-click index.html and select Open with Live Server to see your website in the browser.

Now, you can start coding and see the changes you make to your website in real time!
