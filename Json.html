JSON

JSON stands for JavaScript Object Notation.

It is a lightweight text-based data format used to store and exchange information between applications, websites, and servers.

JSON looks similar to JavaScript object syntax, but it follows stricter rules.

Example of JSON data


{
    "name": "Ravi",
    "age": 20,
    "course": "JavaScript",
    "isStudent": true
}

Important JSON methods

Method Descrition
JSON.stringify() Converts a JavaScript value into a JSON string.
JSON.parse() Converts a valid JSON string into a JavaScript value.

Example: JSON.stringify()

It converts a JavaScript object into a JSON string.


const student = {
    name: "Ravi",
    age: 20
};

const jsonData = JSON.stringify(student);

console.log(jsonData);
console.log(typeof jsonData);

Output:


{"name":"Ravi","age":20}
string

Example: JSON.parse()

It converts a JSON string into a JavaScript value.


const jsonData = '{"name":"Ravi","age":20}';

const student = JSON.parse(jsonData);

console.log(student.name);
console.log(student.age);

Output:


Ravi
20

Important JSON rules:

  1. Property names must be written using double quotes.

  2. String values must use double quotes.

  3. JSON does not support functions.

  4. JSON does not support undefined.

  5. JSON does not allow comments.

When should you use JSON?

  • When sending data between a frontend and backend.

  • When working with APIs.

  • When storing structured data.

  • When exchanging information between applications.
