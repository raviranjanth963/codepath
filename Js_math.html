Math

The Math object provides built-in mathematical constants and methods.

It is used for calculations such as rounding numbers, finding square roots, generating random numbers, and calculating powers.

Important: Unlike most built-in objects, Math is not a constructor. You use its properties and methods directly.

mportant Math properties

Property Description value
Math.PI Mathematical value of pi Approximately 3.14159
Math.E Euler's number Approximately 2.71828
Math.SQRT2 Square root of 2 Approximately 1.41421
Math.LN2 Natural logarithm of 2 Approximately 0.69314

Important Math methods

Method Description
Math.round() Rounds to the nearest integer.
Math.floor() Rounds down to the nearest integer.
Math.ceil() Rounds up to the nearest integer.
Math.trunc() Removes the decimal portion.
Math.max() Returns the largest value.
Math.min() Returns the smallest value.
Math.random() Returns a pseudo-random number from 0 (inclusive) to 1 (exclusive).
Math.sqrt() Returns the square root.
Math.pow() Raises a number to a specified power.
Math.abs() Returns the absolute value.
Math.sign() Returns the sign of a number.

Example: Math.round()


console.log(Math.round(4.6));
console.log(Math.round(4.3));

Output:


5
4

Example: Math.floor()


console.log(Math.floor(4.9));

Output:


4

Example: Math.ceil()


console.log(Math.ceil(4.1));

Output:


5

Example: Math.max() and Math.min()


console.log(Math.max(10, 20, 30, 40));
// 40

console.log(Math.min(10, 20, 30, 40));
// 10

Example: Math.random()


console.log(Math.random());

This produces a pseudo-random decimal number between 0 and 1.

To generate a random integer between 1 and 10:


let randomNumber = Math.floor(Math.random() * 10) + 1;

console.log(randomNumber);

Example: Math.sqrt()


console.log(Math.sqrt(25));

Output:


5

When should you use Math?

  • When creating calculators.

  • When generating random numbers.

  • When calculating percentages.

  • When working with game scores.

  • When performing scientific calculations.
