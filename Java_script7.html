JavaScript

1. Introduction to JavaScript

JavaScript (JS) is a programming language used to make websites interactive and dynamic. It allows us to respond to user actions, update webpage content, validate forms, and perform calculations.

Examples of JavaScript applications:

  • Displaying alerts and messages.

  • Responding to button clicks.

  • Updating text and HTML elements.

  • Validating login and registration forms.

2. How to Run JavaScript in the Browser Console

You can execute JavaScript directly in Google Chrome without creating a file.

  • Open Google Chrome.

  • Open a webpage.

  • Right-click and select Inspect.

  • Select the Console tab.

  • Type JavaScript code and press Enter.

To clear the console, use Ctrl + L in the Console on most Chrome setups.

Example: Display an alert


alert("Welcome to codepath!");
alert("Start learning JavaScript");

Example: Print a message in the console


console.log("Welcome to codepath!");
console.log("JavaScript is easy to learn.");

Explanation: console.log() displays a message or value in the browser console. You can use it to test your code and debug problems.

3. Adding JavaScript to an HTML File

You can connect JavaScript to an HTML webpage using the <script> tag.


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>JavaScript Lesson</title>
</head>
<body>

    <h1>Welcome to codepath</h1>

    <script src="first.js"></script>
</body>
</html>

Create another file named first.js in the same folder.


console.log("Welcome to codepath!");
alert("Your first JavaScript lesson starts here!");

When you open the HTML file in a browser, the JavaScript code will run.

JavaScript Naming Conventions — Notes

1. Camel Case

In camelCase, the first word starts with a lowercase letter, and every following word starts with a capital letter.

Example 

let fullName = "Ravi Kumar";
let firstName = "Ravi";
let studentAge = 18;

Rule: The first word starts with a lowercase letter; subsequent words start with uppercase letters.

2. Snake Case

In snake_case, words are separated by underscores (_).

Example 

let full_name = "Ravi Kumar";
let first_name = "Ravi";
let student_age = 18;

Rule: Use underscores to separate words.

3. Kebab Case

Example 

full-name
first-name
student-age

Important: Hyphens are not valid in ordinary JavaScript variable names. For example, let full-name = "Ravi"; is invalid syntax.

Kebab case is commonly used for CSS class names and HTML attributes.


<div class="full-name">Ravi Kumar</div>

4. Pascal Case

In PascalCase, every word starts with a capital letter, including the first word.

Example 

let FullName = "Ravi Kumar";
let StudentAge = 18;

Rule: Capitalize the first letter of every word.

PascalCase is commonly used for class names in JavaScript.


class StudentDetails {
    constructor(fullName) {
        this.fullName = fullName;
    }
}

4. Variables in JavaScript

A variable is a named container used to store data in a program.

JavaScript provides three keywords for declaring variables: var, let, and const.


let age = 24;
let name = "Ravi";

console.log(age);
console.log(name);


24
Ravi

Updating a variable


let age = 24;

age = 25;

console.log(age); // 25

You can also increase a number by one:


let age = 24;

age = age + 1;
// Or use:
age++;

console.log(age); // 25

Different values stored in variables


let age = 24;
let name = "Ravi";
let x = null;
let y;

console.log(age, name, x, y);

  • 24 is a number.

  • "Ravi" is a string.

  • null represents an intentional absence of a value.

  • undefined is the value of a declared variable that has not been assigned a value.

5. JavaScript Is Dynamically Typed

JavaScript is a dynamically typed language. This means you do not need to specify a variable's data type when declaring it. The type is determined from the value assigned to it, and a variable can hold values of different types at different times.


let value = 25;
console.log(value); // 25

value = "Hello";
console.log(value); // Hello

Unlike some statically typed languages, JavaScript does not require declarations such as int age = 24.

6. Rules for Naming Variables

Follow these rules when creating variable names:

  • Variable names are case-sensitive. age and Age are different variables.

  • Names can contain letters, digits, underscores (_) and dollar signs ($).

  • A variable name cannot start with a digit.

  • Spaces and hyphens are not allowed in variable names.

  • Reserved keywords such as let, const, and if cannot be used as variable names.

  • Use meaningful names to make your code easier to understand.

Examples: 

let fullName = "Ravi Kumar"; // Valid
let age2 = 20;               // Valid
let _score = 90;             // Valid
let $price = 100;            // Valid

// Invalid variable names:
// let 2age = 20;
// let full-name = "Ravi";
// let full name = "Ravi";

7. Difference Between var, let, and const


var age = 20;
age = 21;

let city = "Delhi";
city = "Patna";

const country = "India";

console.log(age);
console.log(city);
console.log(country);

Important: Use let when a variable needs to be reassigned and const when the variable binding should not be reassigned. var is mainly encountered in older JavaScript code.

A const object can still have its properties updated; const does not make the entire object immutable.

8. Data Types in JavaScript

JavaScript data types are divided into two broad categories.

  1. Primitive Data Types

    2. Primitive values represent individual values.

    • Number: Numeric values such as 10, 25.5

    • String: Text such as "Hello"

    • Boolean: true or false

    • Undefined: A variable without an assigned value

    • Null: An intentional absence of a value

    • BigInt: Very large integers

    • Symbol: Unique identifiers

  2. Non-Primitive Data Types

    3. Objects store collections of data or more complex structures.

    • Object: Stores data as key-value pairs.

    • Array: Stores an ordered collection of values.

    • Function: A reusable block of code.

Using the typeof operator

The typeof operator tells you the type of a value.


let age = 20;
let name = "Ravi";
let isStudent = true;
let x;

console.log(typeof age);       // "number"
console.log(typeof name);      // "string"
console.log(typeof isStudent); // "boolean"
console.log(typeof x);         // "undefined"

Note: typeof null returns "object" because of a historical JavaScript quirk.

9. Objects in JavaScript

An object stores related information in key-value pairs. It is useful for representing real-world entities such as students, employees, and products.

Example: Student object


const student = {
    fullName: "Rahul Kumar",
    age: 20,
    grade: "A",
    isPass: true
};

console.log(student);
console.log(student.fullName);
console.log(student.age);

Output


{ fullName: "Rahul Kumar", age: 20, grade: "A", isPass: true }
Rahul Kumar
20

Accessing object properties

You can access object properties using dot notation or bracket notation.


console.log(student.fullName);
console.log(student["age"]);

Updating object properties


{ student.age = 21;
student.grade = "A+";

console.log(student.age);
console.log(student.grade);

You can update an object's properties even when the object is declared using const.

However, you cannot reassign student to an entirely different object because it was declared using const.

JavaScript

JavaScript (JS) is a lightweight interpreted (or just-in-time compiled) programming language with first-class functions. While it is most well-known as the scripting language for Web pages, many non-browser environments also use it, such as Node.js, Apache CouchDB and Adobe Acrobat. JavaScript is a prototype-based, garbage-collected, dynamic language, supporting multiple paradigms such as imperative, functional, and object-oriented.


JavaScript's dynamic capabilities include runtime object construction, variable parameter lists, function variables, dynamic script creation (via eval), object introspection (via for...in and Object utilities), and source-code recovery (JavaScript functions store their source text and can be retrieved through toString()).


This section is dedicated to the JavaScript language itself, and not the parts that are specific to Web pages or other host environments. For information about APIs that are specific to Web pages, please see Web APIs and DOM.


The standards for JavaScript are the ECMAScript Language Specification (ECMA-262) and the ECMAScript Internationalization API specification (ECMA-402). As soon as one browser implements a feature, we try to document it. This means that cases where some proposals for new ECMAScript features have already been implemented in browsers, documentation and examples in MDN articles may use some of those new features. Most of the time, this happens between the stages 3 and 4, and is usually before the spec is officially published.


Do not confuse JavaScript with the Java programming language — JavaScript is not "Interpreted Java". Both "Java" and "JavaScript" are trademarks or registered trademarks of Oracle in the U.S. and other countries. However, the two programming languages have very different syntax, semantics, and use.
