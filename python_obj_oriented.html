Object-Oriented Python

Introduction to OOP

Object-Oriented Programming (OOP) is a programming approach based on classes and objects.

It helps organize code by combining data and related functionality.

The four main principles of OOP are:

  1. Encapsulation
  2. Inheritance
  3. Polymorphism
  4. Abstraction

Classes and Objects

Class: A class is a blueprint used to create objects.

Object: An object is an instance of a class.

Example:


class Student:
    name = "Aman"
    age = 18

student1 = Student()

print(student1.name)
print(student1.age)

Output:


Aman
18

The init() Method

The __init__() method initializes an object's attributes when the object is created.


class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

student1 = Student("Aman", 18)
student2 = Student("Ravi", 19)

print(student1.name)
print(student2.name)

Understanding self

self refers to the current instance of a class.

It is used to access the object's attributes and methods.


class Student:
    def __init__(self, name):
        self.name = name
    
    def display(self):
        print(self.name)

s1 = Student("Aman")
s1.display()

Class Attributes and Instance Attributes

Class attribute: Shared through the class and normally accessible through its instances.

Instance attribute: Belongs to a particular object.


class Student:
    college = "ADGITM"

    def __init__(self, name):
        self.name = name

s1 = Student("Aman")
s2 = Student("Ravi")

print(s1.college)
print(s2.college)
print(s1.name)

Instance Methods, Class Methods and Static Methods

Instance method:

Works with an object's instance data.


class Student:
    def display(self):
        print("Student details")

s1 = Student()
s1.display()

Class method:

Uses @classmethod and receives the class as cls.


class Student:
    college = "ADGITM"

    @classmethod
    def show_college(cls):
        print(cls.college)

Student.show_college()

Static method:

Uses @staticmethod and does not automatically receive self or cls.


class Student:
    @staticmethod
    def add(a, b):
        return a + b

Encapsulation

Encapsulation means grouping data and methods together and controlling how internal data is accessed.

Python uses naming conventions and properties to manage access.


class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    def get_balance(self):
        return self.__balance

account = BankAccount(5000)

print(account.get_balance())

Here, __balance uses name mangling. It is not absolute security or strict private access.

Inheritance

Inheritance allows a child class to reuse and extend features of a parent class.


class Animal:
    def eat(self):
        print("Animal is eating")

class Dog(Animal):
    def bark(self):
        print("Dog is barking")

d = Dog()

d.eat()
d.bark()

Types of inheritance:

  • Single inheritance
  • Multiple inheritance
  • Multilevel inheritance
  • Hierarchical inheritance
  • Hybrid inheritance

Polymorphism

Polymorphism means one interface or method name can work in different ways depending on the object.


class Dog:
    def sound(self):
        print("Bark")

class Cat:
    def sound(self):
        print("Meow")

for animal in [Dog(), Cat()]:
    animal.sound()

Method Overriding

Method overriding occurs when a child class provides its own implementation of a method inherited from the parent class.


class Animal:
    def sound(self):
        print("Animal sound")

class Dog(Animal):
    def sound(self):
        print("Bark")

d = Dog()
d.sound()

Abstraction

Abstraction means exposing essential functionality while hiding implementation details.

Python supports abstraction through the abc module.


from abc import ABC, abstractmethod

class Shape(ABC):

    @abstractmethod
    def area(self):
        pass

class Rectangle(Shape):
    def __init__(self, length, width):
        self.length = length
        self.width = width

    def area(self):
        return self.length * self.width

r = Rectangle(10, 5)
print(r.area())

Output:


50

Constructors and Destructors

Constructor: __init__() initializes an object.

Destructor: __del__() is called when an object is being finalized, although its exact timing should not be relied upon.


class Demo:
    def __init__(self):
        print("Object created")

    def __del__(self):
        print("Object finalized")

obj = Demo()

Operator Overloading

Operator overloading allows operators to work with user-defined objects through special methods.


class Number:
    def __init__(self, value):
        self.value = value

    def __add__(self, other):
        return self.value + other.value

a = Number(10)
b = Number(20)

print(a + b)

Output:


30
