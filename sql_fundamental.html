1. What is SQL?

SQL stands for Structured Query Language.

It is used to communicate with relational databases. It allows us to create tables, insert records, retrieve data, update information and delete records.

Example:


SELECT * FROM students;

This retrieves all records from the students table.

2. What is a Database?

A database is an organized collection of data.

Example:

Student ID Name Age City
101 Rahul 20 delhi
102 Priya 19 Mumbai
103 Aman 21 Patna

A college can use a database to store student records, course information, attendance and examination results.

3. What are DBMS and RDBMS?

DBMS: Software used to create, manage and access databases.

RDBMS: A database management system that stores information in relational tables and supports relationships between them.

Examples of RDBMS:

  • MySQL
  • PostgreSQL
  • Oracle Database
  • Microsoft SQL Server

4. What are the five SQL command categories?

Category Full form Commands
DDL Data Definition Language CREATE, ALTER, DROP, TRUNCATE
DML Data Manipulation Language INSERT, UPDATE, DELETE
DQL Data Query Language SELECT
DCL Data Control Language GRANT, REVOKE
TCL Transaction Control Language COMMIT, ROLLBACK, SAVEPOINT
