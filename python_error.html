Files & Error Handling

Introduction to File Handling

File handling allows a program to create, read, write and modify files.

Python provides the built-in open() function.

Syntax:



file = open("filename.txt", "mode")

File Opening Modes

Mode Meaning
r Read a file
w Write; creates or overwrites a file
a Append content to a file
x Create a new file; fails if it exists
r+ Read and write
w+ Write and read; truncates existing content
a+ Append and read
b Binary mode modifier
t Text mode modifier (default)

Writing to a File



file = open("notes.txt", "w")

file.write("Welcome to CodePath")

file.close()

The w mode creates the file if it does not exist and replaces its previous contents if it does.

Reading a File



file = open("notes.txt", "r")

content = file.read()

print(content)

file.close()

Reading Lines

readline(): Reads one line.



file = open("notes.txt", "r")

print(file.readline())

file.close()

readlines(): Reads all lines and returns them as a list.



file = open("notes.txt", "r")

print(file.readlines())

file.close()

Appending to a File

Append mode adds new content without replacing existing content.



file = open("notes.txt", "a")

file.write("\nPython is easy to learn.")

file.close()

The with Statement

The with statement manages file closing automatically.


with open("notes.txt", "r") as file:
    content = file.read()
    print(content)

This is the recommended approach for ordinary file operations.

File Position Methods

  • tell() returns the current file position.
  • seek() changes the file position.

with open("notes.txt", "r") as file:
    print(file.tell())

    file.read(5)

    print(file.tell())

    file.seek(0)

    print(file.read())

Working with Directories

Python's os module helps interact with the operating system.


with os

print(os.getcwd())

Other useful functions:


os.listdir()
os.mkdir("my_folder")
os.path.exists("notes.txt")

Introduction to Errors and Exceptions

An error is a problem that prevents a program from working as intended.

Common Python errors:

Error Meaning
SyntaxError Incorrect syntax
NameError Undefined name
TypeError Incorrect type operation
ValueError Invalid value
IndexError Invalid sequence index
KeyError Missing dictionary key
ZeroDivisionError Division by zero
FileNotFoundError File does not exist
ImportError Import problem

try and except

The try block contains code that might raise an exception. The except block handles a matching exception.


try:
    num = int(input("Enter a number: "))
    print(10 / num)

except ZeroDivisionError:
    print("Cannot divide by zero")

except ValueError:
    print("Please enter a valid integer")

else Statement

The else block runs if no exception occurs in the try block.


try:
    num = int(input("Enter a number: "))
    print(10 / num)

except ValueError:
    print("Invalid input")

except 
    print("Your number is:", num)

finally Statement

The finally block runs whether an exception occurs or not.


try:
    print("Program started")

except Exception:
    print("An error occurred")

finally 
    print("Program finished")

Raising Exceptions

The raise keyword allows you to raise an exception deliberately.


age = -5

if age < 0:
    raise ValueError("Age cannot be negative")

Creating Custom Exceptions

You can create your own exception classes by inheriting from Exception.


class InvalidAgeError(Exception):
    pass

age = 15

try:
    if age < 18:
        raise InvalidAgeError("Age must be 18 or above")

except InvalidAgeError as error:
    print(error)

Practical Example – Safe Calculator


try:
    a = float(input("Enter first number: "))
    b = float(input("Enter second number: "))

    result = a / b

except ZeroDivisionError:
    print("Cannot divide by zero")

except ValueError:
    print("Enter valid numbers")

else:
    print("Result:", result)

finally:
    print("Calculator closed")
