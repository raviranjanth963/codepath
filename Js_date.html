Date

The Date object is used to work with dates and times in JavaScript.

It allows you to create dates, retrieve date information, and modify date and time values.

Creating a Date object


const today = new Date();

console.log(today);

This returns the current date and time.

Creating a specific date


const birthday = new Date("2005-08-15");

console.log(birthday);

Important Date methods

Method Description
getDate() Returns the day of the month (1–31).
getDay() Returns the day of the week (0–6).
getMonth() Returns the month (0–11).
getFullYear() Returns the four-digit year.
getHours() Returns the hour (0–23).
getMinutes() Returns the minutes (0–59).
getSeconds() Returns the seconds (0–59).
getTime() Returns milliseconds since January 1, 1970 (UTC)
setDate() Changes the day of the month.
setMonth() Changes the month.
setFullYear() Changes the year.
toISOString() Converts the date into ISO 8601 format.
toLocaleDateString() Formats a date according to a locale.
toLocaleTimeString() Formats a time according to a locale

Example: Getting the current date


const today = new Date();

console.log(today.getDate());
console.log(today.getMonth() + 1);
console.log(today.getFullYear());

Why do we add 1 to the month?

JavaScript month values start at 0.

  • January = 0

  • February = 1

  • March = 2

  • December = 11

Example: Getting the current time


const now = new Date();

console.log(now.getHours());
console.log(now.getMinutes());
console.log(now.getSeconds());

Example: Displaying a formatted date


const today = new Date();

console.log(today.toLocaleDateString("en-IN"));

When should you use Date?

  • >When displaying the current date and time.

  • When creating a digital clock.

  • When calculating age.

  • When managing event dates.

  • When creating countdown timers.
