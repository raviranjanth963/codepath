Other Important Built-in Objects

Boolean

The Boolean object represents a logical value: true or false.

Most JavaScript programs use Boolean values for conditions and decision-making.

example


let isLoggedIn = true;
let isAdmin = false;

console.log(isLoggedIn);
console.log(isAdmin);

Boolean() function

The Boolean() function converts a value into either true or false.


console.log(Boolean(1));        // true
console.log(Boolean(0));        // false
console.log(Boolean("Hello"));  // true
console.log(Boolean(""));       // false
console.log(Boolean(null));     // false

Important: Values such as false, 0, -0, 0n, "", null, undefined, and NaN are falsy. Most other values are truthy, including empty arrays and empty objects.

Use primitive Boolean values in normal programming rather than creating Boolean wrapper objects with new Boolean().



BigInt

BigInt is a JavaScript built-in type used to represent integers larger than the maximum safe integer supported by the ordinary Number type.

example


const bigNumber = 123456789012345678901234567890n;

console.log(bigNumber);
console.log(typeof bigNumber);

Output:


123456789012345678901234567890n
bigint

BigInt calculations


const a = 100n;
const b = 200n;

console.log(a + b); // 300n
console.log(a * b); // 20000n

Important rules:

  • Add n at the end of an integer literal to create a BigInt.

  • BigInt and Number values cannot be mixed directly in arithmetic operations.

  • BigInt is used for very large integer calculations.

  • BigInt does not support decimal values.

Symbol

Symbol is a built-in primitive type used to create unique identifiers.

Every Symbol created using Symbol() is unique, even if the same description is provided.

Example


const id1 = Symbol("id");
const id2 = Symbol("id");

console.log(id1 === id2);

Output:


false

Using Symbol as an object property


const id = Symbol("studentId");

const student = {
    name: "Ravi",
    [id]: 101
};

console.log(student.name);
console.log(student[id]);

Output:


Ravi
101

When should you use Symbol?

  • When creating unique property keys.

  • When avoiding accidental property-name conflicts.

  • When implementing special object behaviors using well-known Symbols.



Map

A Map is a built-in collection that stores data in key-value pairs.

Unlike ordinary objects, Map keys can be values of any type, including objects and functions.

Creating a Map


const student = new Map();

student.set("name", "Ravi");
student.set("age", 20);
student.set("course", "JavaScript");

console.log(student);

Important Map methods

Method Description
set() Adds or updates a key-value pair.
get() Returns the value associated with a key.
has() Checks whether a key exists.
delete() Removes a key-value pair.
clear() Removes all entries.
keys() Returns an iterator of keys.
values() Returns an iterator of values.
entries() Returns an iterator of key-value pairs.
size Returns the number of entries.

Example


const student = new Map();

student.set("name", "Ravi");
student.set("age", 20);

console.log(student.get("name"));
console.log(student.has("age"));
console.log(student.size);

Output:


Ravi
true
2


Set

A Set is a built-in collection used to store unique values.

It automatically prevents duplicate values from being stored.

Creating a Set


const numbers = new Set([10, 20, 20, 30, 30, 40]);

console.log(numbers);

Output:


Set(4) {10, 20, 30, 40}

Important Set methods

Method description
add() Adds a new value.
has() Checks whether a value exists.
delete() Removes a value.
clear() Removes all values.
size Returns the number of unique values.
values() Returns an iterator of values.

Example


const fruits = new Set();

fruits.add("Apple");
fruits.add("Mango");
fruits.add("Banana");
fruits.add("Apple");

console.log(fruits);
console.log(fruits.size);

Output:


Set(3) {"Apple", "Mango", "Banana"}
3

When should you use Set?

  • When removing duplicate values.

  • When storing unique user IDs.

  • When checking whether a value exists in a collection.
