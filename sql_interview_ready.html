Interview Ready

Placement preparation

Goal: Prepare students to answer theoretical and practical SQL interview questions.

Divide this section into three levels.

Beginner Interview Questions

Q1. What is SQL?

SQL stands for Structured Query Language. It is used to communicate with relational databases.

Q2. What is MySQL?

MySQL is a relational database management system that uses SQL.

Q3. What is DBMS?

DBMS is software used to create, access and manage databases.

Q4. What is RDBMS?

RDBMS is a database system that stores information in relational tables and supports relationships between tables.

Q5. What is a Primary Key?

A primary key uniquely identifies every record in a table.

Q6. What is a Foreign Key?

A foreign key references a key in another table to establish a relationship.

Q7. What is NULL?

NULL represents a missing or unknown value.

Q8. What is the difference between CHAR and VARCHAR?

CHAR is fixed-length, whereas VARCHAR is variable-length.

Intermediate Interview Questions

Q9. What is the difference between DELETE, TRUNCATE and DROP?

DELETE removes rows, TRUNCATE removes all rows while retaining table structure, and DROP removes the table itself.

Q10. What is the difference between WHERE and HAVING?

WHERE filters rows before grouping, whereas HAVING filters grouped results.

Q11. What is JOIN?

JOIN combines records from related tables using a join condition.

Q12. What is the difference between INNER JOIN and LEFT JOIN?

INNER JOIN returns matching rows. LEFT JOIN returns every row from the left table and matching rows from the right table.

Q13. What is the difference between UNION and UNION ALL?

UNION removes duplicate result rows. UNION ALL keeps them.

Q14. What is a Subquery?

A subquery is a query written inside another query.

Q15. What is Normalization?

Normalization organizes tables to reduce unnecessary data duplication and improve integrity.

Q16. What is an Index?

An index is a data structure that can help improve data retrieval performance.

Advanced Interview Questions

Q17. What are ACID properties?

Atomicity, Consistency, Isolation and Durability.

Q18. What is a View?

A view is a virtual table created from a stored SELECT query.

Q19. What is a CTE?

A Common Table Expression is a named temporary result set defined using WITH.

Q20. What is a Window Function?

A window function calculates values across related rows without collapsing the rows into a grouped result.

Q21. What is a Trigger?

A trigger is a database object that automatically executes when a specified event occurs.

Q22. What is a Stored Procedure?

A stored procedure is a collection of SQL statements stored in a database and executed when called.

Q23. What is a Composite Key?

A composite key uses two or more columns together to uniquely identify a record.

Q24. What is a Correlated Subquery?

A correlated subquery refers to columns from the outer query.

Practical interview queries

Question 1: Find the second-highest salary.


SELECT MAX(salary) AS second_highest_salary
FROM employees
WHERE salary < (
    SELECT MAX(salary)
    FROM employees
);

Question 2: Find employees earning more than the average salary.


SELECT *
FROM employees
WHERE salary > (
    SELECT AVG(salary)
    FROM employees
);

Question 3: Count employees in each department.


SELECT department_id, COUNT(*) AS total_employees
FROM employees
GROUP BY department_id;

Question 4: Find duplicate email addresses.


SELECT email, COUNT(*) AS total
FROM employees
GROUP BY email
HAVING COUNT(*) > 1;

Question 5: Find the highest-paid employee in each department.


SELECT e.*
FROM employees e
JOIN (
    SELECT department_id, MAX(salary) AS highest_salary
    FROM employees
    GROUP BY department_id
) d
ON e.department_id = d.department_id
AND e.salary = d.highest_salary;
