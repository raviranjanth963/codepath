Joins & Relationships

Relational database concepts

Goal: Understand how tables connect to each other and how to retrieve information from multiple tables.

1. What is a Primary Key?

A Primary Key is used to uniquely identify each record in a table.


CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(100)
);

The primary key must be unique and cannot contain NULL.

2. What is a Foreign Key?

A Foreign Key connects two related tables.

Parent table:


CREATE TABLE departments (
    department_id INT PRIMARY KEY,
    department_name VARCHAR(100)
);

Child table:


CREATE TABLE employees (
    employee_id INT PRIMARY KEY,
    employee_name VARCHAR(100),
    department_id INT,
    FOREIGN KEY (department_id)
        REFERENCES departments(department_id)
);

The employee's department ID must reference an existing department unless the column is NULL and allows it.

3. SQL Constraints

Constraint Purpose
PRIMARY KEY Unique identification
FOREIGN KEY Maintain relationships
NOT NULL Prevent NULL
UNIQUE Prevent duplicate non-NULL values
CHECK Validate a condition
DEFAULT Provide a default value
AUTO_INCREMENT Generate numeric IDs

4. Types of Relationships

One-to-One: One record is connected to one record.

Example: One person and one passport.

One-to-Many: One record is connected to multiple records.

Example: One department and many employees.

Many-to-Many: Multiple records in one table can connect with multiple records in another table.

Example: Students and courses, connected through an enrollment table.

5. INNER JOIN

Returns matching records from both tables.


SELECT students.name, courses.course_name
FROM students
INNER JOIN enrollments
    ON students.student_id = enrollments.student_id
INNER JOIN courses
    ON enrollments.course_id = courses.course_id;

6. LEFT JOIN

Returns every record from the left table and matching records from the right table.


SELECT students.name, enrollments.course_id
FROM students
LEFT JOIN enrollments
ON students.student_id = enrollments.student_id;

7. RIGHT JOIN

Returns every record from the right table and matching records from the left table.


SELECT students.name, enrollments.course_id
FROM students
RIGHT JOIN enrollments
ON students.student_id = enrollments.student_id;

8. FULL OUTER JOIN

MySQL does not have a direct FULL OUTER JOIN keyword.

It can be emulated using LEFT JOIN and RIGHT JOIN with UNION.


SELECT students.name, enrollments.course_id
FROM students
LEFT JOIN enrollments
ON students.student_id = enrollments.student_id

UNION

SELECT students.name, enrollments.course_id
FROM students
RIGHT JOIN enrollments
ON students.student_id = enrollments.student_id;

9. CROSS JOIN

Combines every record in the first table with every record in the second table.


SELECT *
FROM students
CROSS JOIN courses;

10. SELF JOIN

Joins a table to itself.


SELECT
    e.name AS employee,
    m.name AS manager
FROM employees e
LEFT JOIN employees m
ON e.manager_id = m.employee_id;

11. Cascading

ON DELETE CASCADE automatically deletes child records when the referenced parent record is deleted.


FOREIGN KEY (department_id)
REFERENCES departments(department_id)
ON DELETE CASCADE

ON UPDATE CASCADE automatically updates matching foreign-key values when the referenced parent key changes.
